# Image Brief

Every photo location in the site is an `ImageSlot` component with a fixed
aspect ratio, alt-text brief and a tasteful tinted placeholder. Real
photography should be supplied to match these briefs. All imagery: authentic,
natural light, Sri Lankan educational and business environments with an
international corporate finish. Slightly cool, teal-leaning color grade.
Rounded xl corners. No clip-art, no excessive handshakes, no fake logos.

## Shot categories

### Students
- Studying / focused work (library, desk)
- Workshops / group learning
- Interview preparation (mock interview)
- Teamwork / collaboration
- Internship in progress (office environment)

### Education providers
- Campuses (exterior, architectural)
- Academic meetings / faculty discussion
- Career sessions / employability workshops
- Partnership meetings (institution + CareerMesh)

### Employers
- Offices (modern, professional)
- Mentoring (senior + junior)
- Interviews (employer side)
- Collaboration / project work

### Graduate recruiters
- HR meetings / strategy
- Assessment centers
- Trainee workshops
- Leadership development sessions

### Technology (ClientFlow)
- Dashboard interfaces (use coded mockups, not photos)
- Pipeline / automation illustrations (coded SVG)
- Analytics visualizations (coded)

## Rules
- Consistent color grade across all photos.
- No repeated images across sections.
- No unlicensed stock.
- No fake university or employer logos.
- Optimize every image for the web (WebP/AVIF, responsive sizes).
- Provide descriptive alt text for each slot.
